# Logo asset

`mahrukh-logo.png` is the authentic Mahrukh Fumigation Services logo,
supplied directly by the business owner (a cleaned-up but faithful digital
version of the physical letterhead logo). It is used exactly as provided —
no redesign, recoloring, redrawing, or modernization (Constitution
Principle IV) — only CSS resizing, via `components/logo-mark.tsx`, in the
site header and footer.

The favicon set under `public/favicon/` is cropped from this same file's
circular emblem (not redrawn) — see `app/layout.tsx` for how it's wired in.
